# Support

PrismTrail is a community-maintained open-source project.

## Questions and setup help

Use [GitHub Discussions](https://github.com/ENOSTECH-inc/prismtrail/discussions) for:

- setup and configuration questions
- adapter ideas and design discussion
- usage patterns and examples
- help distinguishing a bug from an environment or permission issue

Please share only sanitized examples. Never post credentials, tokens, customer data, production
resource identifiers, prompts, responses, SQL results, or private Google Cloud metadata.

## Bugs and feature requests

Use the repository's structured
[issue forms](https://github.com/ENOSTECH-inc/prismtrail/issues/new/choose) for reproducible bugs
and actionable feature requests.

## Security

Do not open a public issue for a vulnerability. Follow [SECURITY.md](./SECURITY.md) and use
[private vulnerability reporting](https://github.com/ENOSTECH-inc/prismtrail/security/advisories/new).

There is currently no guaranteed response time or commercial support SLA.
